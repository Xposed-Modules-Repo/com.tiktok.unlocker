# GlobalKit

TikTok 国际版区域伪装 LSPosed / LSPatch 模块，开箱即用。

## 功能

伪装以下设备环境信息以绕过 TikTok 区域限制：

- **SIM 国家码** — 切换至目标地区运营商识别
- **网络国家码** — 模拟目标区域网络归属
- **运营商名称/编号** — 伪造运营商身份
- **系统语言** — 自动切换为区域对应语言
- **系统时区** — 同步目标区域时间
- **GPS 经纬度** — 伪装地理位置坐标

## 使用步骤

1. 安装 LSPosed 或 LSPatch
2. 启用模块并勾选 TikTok
3. 在模块设置中选择目标地区
4. 清除 TikTok 数据后重新打开
