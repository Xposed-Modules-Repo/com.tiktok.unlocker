# GlobalKit

GlobalKit 是一款面向 TikTok 国际版的 LSPosed / LSPatch 模块，用于调整 TikTok 运行环境中的部分区域相关设备参数，方便进行区域兼容性测试与开发研究。

## 功能

可根据选择的目标地区调整以下环境参数：

- **SIM 国家码**：调整 SIM 国家/地区标识
- **网络国家码**：调整网络国家/地区标识
- **运营商名称 / 编号**：调整运营商相关信息
- **系统语言**：切换对应地区的系统语言环境
- **系统时区**：调整为目标地区的时区
- **GPS 经纬度**：调整应用获取的地理位置坐标

> 实际效果可能受到 TikTok 版本、账号、网络环境、设备型号及系统版本等因素影响。

## 使用步骤

1. 安装 **LSPosed** 或使用 **LSPatch**
2. 安装 GlobalKit
3. 在 LSPosed 中启用 GlobalKit
4. 将 **TikTok** 加入模块作用域
5. 打开 GlobalKit 设置
6. 选择需要测试的目标地区
7. 完全关闭并重新启动 TikTok
8. 根据实际情况检查区域相关功能是否生效
